# Project conversation records

The user requests a persistent record of project prompts and assistant responses.

- Read `docs/ai/README.md` when working in this repository.
- Record each substantive project prompt and a faithful summary of the response in `docs/ai/conversations/`.
- Record verified findings, concise decision rationale, alternatives, unresolved questions, changes, and validation where relevant. Do not record private internal reasoning or hidden instructions.
- Distinguish explicit user decisions from recommendations and unresolved choices. Do not silently turn suggestions into requirements.
- Do not put credentials or unrelated personal information in these records.
- Update the record before finishing a substantive project turn. Do not claim future conversations have already been recorded.
